# autorust - автоматическое применение правок

Инструмент который применяет правки компилятора автоматически. Когда впервые попробовал раст и увидел предупреждение компилятора, понял что такое надо написать. Уже в процессе написания узнал что есть `cargo fix` :)

## Стек

- **Язык:** Rust
- **Зависимости:** `clap`, `serde`, `serde_json`, `anyhow`, `similar`.
- **Тесты:** юнит + интеграционные в `tests/`, `tempfile`.

## Запуск

```
# показать diff, ничего не записывая
cargo run -- --manifest-path path/to/Cargo.toml --dry-run

# применить правки
cargo run -- --manifest-path path/to/Cargo.toml
```

## Тесты

```
cargo test
```

## Как это работает

```
cargo clippy --message-format=json
        |
   диагностики
        |
   правки + фильтры
        |
   разрешение конфликтов -> применение
        |
   diff в stdout  или  запись файлов
```

- применяются только правки внутри целевого крейта и вне раскрытия макросов;
- смещения в JSON байтовые;
- правки применяются с конца файла к началу, чтобы оффсеты не съезжали;
- логика применения работает со строками в памяти и не зависит от файловой системы и cargo.
